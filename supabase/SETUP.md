# Настройка Supabase для ДВИЖ

Нужно сделать 3 вещи в дашборде Supabase. Делается один раз, ~5 минут.

## 1. Создать таблицу профилей

Dashboard → **SQL Editor** → **New query** → вставь содержимое файла
[`schema.sql`](./schema.sql) → нажми **Run**.

Это создаёт таблицу `profiles`, защиту RLS (каждый видит только свой профиль)
и триггер, который автоматически заводит профиль при регистрации.

## 2. Включить вход по коду (а не по ссылке)

По умолчанию Supabase шлёт письмо со *ссылкой*. Нам нужен **6-значный код**.

Dashboard → **Authentication** → **Emails** → шаблон **Magic Link** →
замени тело письма на это и сохрани:

```html
<h2>Твой код для входа в ДВИЖ</h2>
<p>Введи этот код в приложении:</p>
<p style="font-size:28px;font-weight:bold;letter-spacing:4px">{{ .Token }}</p>
<p>Код действует 1 час. Если ты не запрашивал вход — просто проигнорируй письмо.</p>
```

Ключевой момент — `{{ .Token }}`. Именно он выводит 6-значный код.

## 3. Проверить, что email-провайдер включён

Dashboard → **Authentication** → **Sign In / Providers** → **Email** должен быть
**включён**. «Confirm email» можно оставить как есть — для входа по коду это не мешает.

---

## Готово

После этого запускай приложение (`npx expo start`), вводи почту → получаешь код →
входишь. У каждого пользователя свой профиль с монетами, хайпом и питомцем,
который сохраняется в облаке.

## Безопасность

- В приложении (`lib/supabase.ts`) лежит только **publishable**-ключ — он
  предназначен для клиента, это нормально.
- **Секретный** ключ (`sb_secret_...`) НИКОГДА не кладём в код приложения —
  только в серверные Edge Functions (это понадобится на шаге с AI-генерацией квестов).
- Раз секретный ключ засветился — лучше перевыпусти его:
  Settings → API Keys → Rotate secret key.
