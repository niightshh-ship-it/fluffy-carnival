# ДВИЖ

Мобильная игра-приложение. AI гейм-мастер выдаёт реальные квесты в городе, пользователи снимают пруфы, зарабатывают коины и растят питомца Хайпожорика.

## Стек

- **Frontend:** React Native + Expo (SDK 52)
- **Роутинг:** Expo Router v4 (файловая навигация)
- **Backend:** Supabase (БД, авторизация, storage, realtime) — *Step 2*
- **AI квесты:** Supabase Edge Function → Anthropic API — *Step 3*

## Запуск

```bash
npm install
npx expo start
```

Открой в Expo Go (сканируй QR) или нажми `i`/`a` для iOS/Android симулятора.

## Структура

```
app/
  _layout.tsx          # Root: загрузка шрифтов, StatusBar
  (tabs)/
    _layout.tsx        # Tab-бар (5 вкладок)
    dvizh.tsx          # Главный экран — квесты
    feed.tsx           # Лента пруфов
    pet.tsx            # Хайпожорик
    challenges.tsx     # Вызовы сообществу
    profile.tsx        # Профиль, XP, достижения
constants/
  tokens.ts            # Все дизайн-токены (цвета, шрифты, экономика)
components/ui/
  Card.tsx             # Базовая карточка с опциональным свечением
  RarityBadge.tsx      # Бейдж редкости (Обычный/Редкий/Эпик/Легендарка)
  StatBar.tsx          # Полоска прогресса для статов питомца
```

## Дизайн-система

Тёмный аркадный стиль. Фон `#0b0c10`, акценты — лайм/розовый/золото/нефрит.
Все токены в `constants/tokens.ts`. Менять экономику коинов — только там (объект `Economy`).
